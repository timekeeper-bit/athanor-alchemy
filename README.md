# 炼金工坊 Athanor Alchemy

Minecraft Java 26.3 的 Fabric 炼金模组。把物品**析解**成八种基础要素，再在**炼金熔炉**多方块结构里把要素**重组**成新物品。

需要：Fabric Loader 0.19.5 及以上、Fabric API（0.162.0+26.3）、Java 25。

## 玩法

1. **析解台**：放入物品，每件 4 秒拆成要素结晶（土、水、火、风、秩序、混沌、生命、金属）。物品提示里会显示它含有的要素。
2. **炼金熔炉**：按下面的结构搭好（核心正面会亮起），把要素结晶放进左上的要素槽，它们会被吸进要素池；在催化物槽放一个催化物，熔炉就按配方消耗要素，在产物槽炼出成品。
3. 两台机器都支持漏斗：析解台上方进料、侧面和下方出结晶；熔炉上方进结晶、侧面进催化物、下方出成品。

### 炼金熔炉结构（3×3×3）

核心放在正面中间一层的中央，结构向核心背后延伸 3 格：

| 层 | 内容 |
|---|---|
| 底层 | 9 格：中心是岩浆块，其余 8 块炼金砖 |
| 中层 | 正面中央是核心；正中心留空（炉膛）；左右两侧中间是炼金玻璃；其余 5 块炼金砖 |
| 顶层 | 9 块炼金砖 |

空手右击核心时，如果结构不完整，聊天栏会提示第一个出错的位置和需要的方块。

### 合成

| 产物 | 配方 |
|---|---|
| 炼金砖 ×8 | 8 石砖围 1 铜锭 |
| 炼金玻璃 ×4 | 4 玻璃十字围 1 红石 |
| 析解台 | 上排 3 铁锭；中排 铁锭、炼药锅、铁锭；下排 3 平滑石 |
| 炼金熔炉核心 | 上排 炼金砖、金锭、炼金砖；中排 炼金砖、高炉、炼金砖；下排 3 炼金砖 |

### 新物品

- **矿物磁铁**：右击把 5 格内的矿石（最多 32 块）按钻石镐的效果采下，掉落物直接进背包；潜行右击扫描 16 格内的矿石并在聊天栏列出数量。耐久 384，每块矿 1 点，冷却 2 秒。
- **引物磁石**：右击开关（开启时发光）。开启后放在背包任意位置，会把 8 格内的掉落物和经验球吸到身边。

## 构建

```bash
./gradlew build      # 编译并运行服务端游戏测试，成品在 build/libs/
./gradlew runClient  # 启动测试客户端
```

贴图和 json 资源由脚本生成：`python3 tools/gen_textures.py`（需要 Pillow）、`python3 tools/gen_assets.py`。

设计细节见 [docs/设计文档.md](docs/设计文档.md)。
