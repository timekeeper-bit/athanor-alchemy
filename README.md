# 炼金工坊 Athanor Alchemy

Minecraft Java 26.3 的 Fabric 魔法炼金模组，灵感来自神秘时代和古代炼金术。把物品**析解**成八种基础要素，把要素**合成**为六种复合要素，在**炼金熔炉**多方块结构里**重组**成新物品，再用**灌注仪式**制作护符、贤者之石等魔法物品。2.0 加入了**大业**：盐硫汞三本原、黑化到赤化的四个阶段、灵气与瘴气的世界规则、新矿脉和一批新器具。游戏内的**翠玉录**是完整的说明书。

需要：Fabric Loader 0.19.5 及以上、Fabric API（0.162.0+26.3）、Java 25。

## 玩法

1. **析解台**：放入物品，每件 4 秒拆成要素结晶（土、水、火、风、秩序、混沌、生命、金属）。物品提示里会显示它含有的要素。
2. **炼金熔炉**：按下面的结构搭好（核心正面会亮起），把要素结晶放进左上的要素槽，它们会被吸进要素池；在催化物槽放一个催化物，熔炉就按配方消耗要素，在产物槽炼出成品。
3. 两台机器都支持漏斗：析解台上方进料、侧面和下方出结晶；熔炉上方进结晶、侧面进催化物、下方出成品。

### 炼金熔炉结构（3×3×3）

核心放在正面中间一层的中央，结构向核心背后延伸 3 格：

| 层 | 内容 |
|---|---|
| 底层 | 9 格：中心是岩浆块，其余 8 块炼金砖 |
| 中层 | 正面中央是核心；正中心留空（炉膛）；左右两侧中间是炼金玻璃；其余 5 块炼金砖 |
| 顶层 | 9 块炼金砖 |

空手右击核心时，如果结构不完整，聊天栏会提示第一个出错的位置和需要的方块。

### 灌注仪式（大型仪式）

1. 放下**灌注祭坛**，在它周围同一高度的 8 个位置放**奥术基座**：东南西北各距离 3 格，四个斜角各距离 (2, 2)。
2. 右击祭坛放上中心物品，右击基座放上材料（每个基座 1 个，物品会悬浮显示）。空手右击取回。
3. 用**炼金法杖**右击祭坛开始仪式。仪式期间粒子从各基座飞向祭坛，结束时降下一道（无伤害的）闪电，中心物品变成成品。
4. 仪式进行中如果有基座上的物品被拿走，仪式失败（材料保留）。基座上不能有多余的物品。

| 中心物品 | 基座材料 | 成品 |
|---|---|---|
| 铁锭 | 魔力 ×2、力量、工具 | 奥能锭 ×2 |
| 钻石 | 奥能锭 ×2、金锭 ×2、魔力、力量、灵魂、光 | 贤者之石 |
| 奥能锭 | 运动 ×2、风 ×2、羽毛、糖 | 疾风护符（速度 II） |
| 奥能锭 | 灵魂 ×2、生命 ×2、金苹果、闪烁的西瓜片 | 生机护符（受伤时生命恢复） |
| 奥能锭 | 光 ×2、金胡萝卜 ×2、蜘蛛眼 | 夜视护符 |
| 奥能锭 | 水 ×2、运动、海带 ×2、海晶碎片 | 潮汐护符（水下呼吸） |
| 奥能锭 | 火 ×2、力量、岩浆膏 ×2、黑曜石 | 余烬护符（抗火） |
| 骨粉 | 生命 ×2、灵魂、土 | 生长之尘 ×8 |

（表中“魔力”“光”等指对应的要素结晶。）

### 新物品

- **矿物磁铁**：右击把 5 格内的矿石（最多 32 块）按钻石镐的效果采下，掉落物直接进背包；潜行右击扫描 16 格内的矿石并在聊天栏列出数量。耐久 384，每块矿 1 点，冷却 2 秒。
- **引物磁石**：右击开关（开启时发光）。开启后放在背包任意位置，会把 8 格内的掉落物和经验球吸到身边。
- **炼金法杖**：右击方块解析它含有的要素；右击灌注祭坛开始仪式。
- **奥能锭**：仪式材料，用来制作护符。
- **五种护符**：放在背包里就持续生效（疾风、生机、夜视、潮汐、余烬）。
- **贤者之石**：右击方块进行嬗变：圆石→石头→石砖、沙子→玻璃、泥土→草方块、铜矿→铁矿→金矿、煤矿→青金石矿、下界岩→灵魂沙（含深板岩版本）。耐久 256。
- **生长之尘**：对方块使用，给周围 5×5 范围施加三次骨粉效果。

## 2.0 大业扩展

### 世界规则：灵气与瘴气

- 每个区块有**灵气**（70 到 130，约 1/24 的区块是**灵脉节点**，灵气 250）。仪式开始时、水银镜传送时、奥能工具自愈时消耗灵气，每 10 秒恢复 1 点。
- 析解、熔炉重组、贤者之石嬗变、万能溶剂、仪式完成都会在区块里留下**瘴气**，每 30 秒消散 1 点。
- 瘴气 ≥ 40：虚弱；≥ 100：饥饿、缓慢，附近的草方块变成砂土、小花小草枯死；≥ 200：凋零。
- 净化：右击撒**盐**（每次 15 点），或放置**盐灯**（每 5 秒 3 点）。喝**万灵药**后 5 分钟内免疫瘴气。
- 用**炼金透镜**右击查看本区块的灵气、瘴气、是否灵脉节点、昼夜和满月。

### 世界规则：天象

- 部分仪式只能在白昼或夜晚开始（下表“时刻”一列）。
- 满月之夜，所有仪式以双倍速度推进。
- 哲人之卵的白化需要露天夜晚，黄化需要露天白昼。

### 新矿脉

| 矿石 | 高度 | 掉落 |
|---|---|---|
| 朱砂矿石（含深层） | -48 ~ 48 | 朱砂 1~2，有经验 |
| 银矿石（含深层） | -56 ~ 32 | 粗银，可熔炼为银锭 |
| 铅矿石（含深层） | -32 ~ 64 | 粗铅，可熔炼为铅锭 |
| 岩盐 | 40 ~ 96 | 盐 2~4 |

银、铅都有金属块。贤者之石可把铅矿点化为银矿、银矿点化为金矿（铅块→银块→金块同理）。

**蒸馏器**放在热源（岩浆块、火、营火、熔岩）上方，每件 5 秒：

| 输入 | 产物 | 副产物 |
|---|---|---|
| 朱砂 | 水银 | 硫磺 |
| 红石 | 水银 | |
| 煤炭 | 硫磺 | |
| 烈焰粉 | 硫磺 ×2 | |
| 火药 | 硫磺 | 盐 |
| 海带 / 干海带块 | 盐 / 盐 ×6 | |
| 骨头 | 盐 | 骨粉 |
| 腐肉 | 盐 | 皮革 |
| 岩盐 | 盐 ×4 | |
| 苹果 / 甜浆果 / 小麦 | 生命之水 | |

盐 + 硫磺 + 水银 + 混沌结晶在工作台无序合成**原初物质**。硫磺 + 盐 + 木炭合成 2 个火药。

### 大业：哲人之卵

**哲人之卵**里放入原初物质，满足条件时每阶段 30 秒：

| 阶段 | 产物 | 条件 |
|---|---|---|
| 黑化 | 黑化之质 | 下方有热源 |
| 白化 | 白化之质 | 头顶露天，夜晚 |
| 黄化 | 黄化之质 | 头顶露天，白昼 |
| 赤化 | 赤化之质 | 下方有热源且头顶露天，完成时消耗 30 灵气 |

用炼金透镜右击哲人之卵可以看到当前阶段、进度和每个条件是否满足。

### 新仪式

| 中心物品 | 基座材料 | 成品 | 灵气 | 时刻 |
|---|---|---|---|---|
| 玻璃瓶 | 水银、硫磺、盐、混沌 ×2、魔力 | 万能溶剂 | 30 | 任意 |
| 白化之质 | 生命之水、盐 ×2、蜂蜜瓶、生命、金胡萝卜 | 万灵药 ×3 | 40 | 任意 |
| 银锭 | 水银 ×2、末影珍珠 ×2、运动 ×2 | 水银镜 | 40 | 夜晚 |
| 黄化之质 | 奥能锭 ×2、附魔之瓶 ×2、力量、工具、绿宝石 | 衔尾蛇之环 | 60 | 任意 |
| 赤化之质 | 金苹果、生命之水 ×2、灵魂 ×2、生命 ×2、闪烁的西瓜片 | 长生灵药 | 70 | 夜晚 |

### 新器具与物品

- **翠玉录**：绿宝石 ×8 + 书。右击打开 12 页说明书。
- **炼金透镜**：查看区块灵气、瘴气、天象；对方块使用查看要素或哲人之卵进度。
- **万能溶剂**：右击方块，把它就地溶解成要素结晶（不能溶解带方块实体的方块和基岩）。耐久 64。
- **水银镜**：潜行右击记住当前位置，右击传送回去（同一维度），消耗所在区块 20 灵气，冷却 5 秒。
- **衔尾蛇之环**：带在身上，每 3 秒消耗 1 点经验为背包里每件受损物品修复 1 点耐久。
- **奥能工具**：镐、斧、锹、剑、锄，介于铁和钻石之间，附魔能力 22，每 10 秒消耗 1 灵气自愈 4 点耐久。
- **生命之水**：生命恢复与力量，伴随反胃。
- **万灵药**：清除全部负面效果，5 分钟“纯净”效果（免疫瘴气）。
- **长生灵药**：回满生命，生命恢复 II、伤害吸收 II，以及 10 分钟“永生”效果：下一次死亡时以半血复生。

## 构建

```bash
./gradlew build      # 编译并运行服务端游戏测试，成品在 build/libs/
./gradlew runClient  # 启动测试客户端
```

贴图和 json 资源由脚本生成：`python3 tools/gen_textures.py`（需要 Pillow）、`python3 tools/gen_assets.py`。

设计细节见 [docs/设计文档.md](docs/设计文档.md)。
