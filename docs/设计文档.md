# 炼金工坊（Athanor Alchemy）设计文档

适用版本：Minecraft Java 26.3，Fabric Loader 0.19.5，Fabric API 0.162.0+26.3。模组 ID：`athanor`。

## 核心玩法

1. **析解**：把物品放进「析解台」，它被拆解成若干「要素结晶」。
2. **储存**：要素结晶是普通物品，可以放箱子、用漏斗运输。
3. **重组**：搭建「炼金熔炉」多方块结构，把要素结晶投入熔炉的要素池，再放一个「催化物」，熔炉按配方消耗要素，炼成新物品。

## 八种要素

| 要素 | ID | 典型来源 |
|---|---|---|
| 土 Terra | `terra` | 泥土、石头、沙子 |
| 水 Aqua | `aqua` | 水桶、海带、冰 |
| 火 Ignis | `ignis` | 煤、烈焰粉、岩浆膏 |
| 风 Aer | `aer` | 羽毛、火药、末影珍珠 |
| 秩序 Ordo | `ordo` | 石英、玻璃、红石 |
| 混沌 Perditio | `perditio` | 圆石、沙砾、腐肉、火药 |
| 生命 Vita | `vita` | 农作物、肉、骨头、树苗 |
| 金属 Metallum | `metallum` | 粗矿、锭、粒 |

物品的要素值写在 `AspectTable` 中，按物品和物品标签两级查找。没有要素值的物品不能放进析解台。按住 Shift 查看物品提示即可看到要素。

**防刷规则**：任何配方产物的要素值总和，都小于炼成它所消耗的要素总和（加上催化物本身的要素）。游戏测试 `recipesCannotLoop` 自动检查这一点。

## 方块

| 方块 | 作用 |
|---|---|
| 析解台 Resolver | 单格机器。1 个输入槽、8 个输出槽（每种要素一个）。每件物品 80 刻。上方漏斗输入，侧面和下方漏斗取出结晶。 |
| 炼金熔炉核心 Athanor Core | 多方块结构的控制器，有界面。 |
| 炼金砖 Athanor Bricks | 结构外壳。 |
| 炼金玻璃 Alchemical Glass | 结构观察窗。 |

## 多方块结构：炼金熔炉（3×3×3）

以核心为正面中心，结构向核心背后延伸 3 格：

- 底层：8 块炼金砖，中心是 **岩浆块**（热源）。
- 中层：核心在正面中央；正中心必须是 **空气**（炉膛）；左右两侧中间是 **炼金玻璃**；其余 5 格炼金砖。
- 顶层：9 块炼金砖。

共 22 块炼金砖、2 块炼金玻璃、1 块岩浆块、1 个核心。核心每 20 刻检查一次结构，结构完整时核心正面发光。空手右击结构不完整的核心，会提示第一个出错的位置和应放的方块。

## 炼金熔炉界面

- 要素输入槽：放入的要素结晶会被吸进要素池（每种上限 512）。
- 催化物槽、产物槽。
- 左侧 8 条要素量条，显示当前配方需要的量（不足显示红色）。
- 进度箭头和结构状态文字。

结构完整、催化物匹配配方、要素足够、产物槽放得下时，熔炉开始炼制（每个配方有自己的时长），完成后消耗 1 个催化物和对应要素。

## 扩展：要素合成与灌注仪式

- 六种复合要素（光、力量、运动、魔力、灵魂、工具），在工作台用两种基础要素结晶无序合成，只作为仪式材料，不进入熔炉要素池。
- 灌注祭坛 + 最多 8 个奥术基座组成的大型仪式。基座位置固定在祭坛周围同一高度：(±3, 0)、(0, ±3)、(±2, ±2)。
- 祭坛和基座各存 1 个物品，用不可拾取、无重力的掉落物实体悬浮显示（每秒校正一次，防止区块重载后重复或丢失），因此不需要客户端渲染器。
- 炼金法杖启动仪式；配方要求基座物品与配方完全一致（无序、不能多也不能少）。仪式中途物品变化即失败，材料保留。完成时生成仅视觉效果的闪电。
- 仪式产物：奥能锭、贤者之石（方块嬗变，耐久 256）、五种护符（携带时刷新状态效果）、生长之尘（5×5 范围三次骨粉）。

## 2.0 扩展：大业

- 古代炼金术主题：盐硫汞三本原、黑化/白化/黄化/赤化四阶段、哲人之卵、万能溶剂、生命之水、长生灵药、万灵药、衔尾蛇、翠玉录、行星金属（银对应月，铅对应土星）。
- 世界规则一：每个区块用 Fabric 数据附件保存灵气、瘴气和上次写入时间，读取时按固定时间边界惰性结算恢复与消散，没人去的区块不消耗性能。灵脉节点由区块坐标散列决定。
- 世界规则二：每 2 秒检查各玩家所在区块，瘴气按 40/100/200 三档施加负面效果并侵蚀地表；纯净效果免疫。
- 世界规则三：仪式有时刻要求（白昼/夜晚），满月夜双倍速度；哲人之卵各阶段有热源、露天、昼夜条件。
- 永生效果通过 `ServerLivingEntityEvents.ALLOW_DEATH` 拦截死亡。
- 翠玉录是带 `written_book_content` 组件的物品，页面是可翻译文本，直接用原版书本界面打开，不需要客户端代码。
- 矿石生成用数据包形式的 `worldgen/feature` 与 `worldgen/placed_feature`，通过 Fabric 生物群系修改 API 加入所有主世界群系。
- 战利品表按 26.3 原版的写法（`"condition": {...}`）生成，1.0 的方块战利品表也改为这种写法，并加了测试确认每个方块都能掉落。
